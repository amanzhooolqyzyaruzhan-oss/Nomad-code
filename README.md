# NOMAD CODE AI
Қазақ тіліндегі фотосурет арқылы көшпенділер символикасын тану веб-сайты.

## Іске қосу
1. Node.js 20+ орнатыңыз.
2. `npm install`
3. `.env.example` файлын `.env` деп көшіріп, `OPENAI_API_KEY` мәнін енгізіңіз.
4. `npm run build`
5. `npm start`
6. Браузерден `http://localhost:3000` ашыңыз.

Әзірлеу кезінде интерфейсті жеке іске қосу: `npm run dev` (API үшін `npm start` қажет; Vite dev проксиі бұл нұсқада орнатылмаған).

## Маңызды
AI фотодан тарихи шындықты әрдайым дәл анықтай алмайды. Ғылыми жобадағы тарихи қорытындыларды этнографиялық дереккөздермен тексеріңіз. Қолданба суретті OpenAI API-ге жібереді. API қолданылуы ақылы болуы мүмкін. API кілтін ешқашан браузер кодына енгізбеңіз.
